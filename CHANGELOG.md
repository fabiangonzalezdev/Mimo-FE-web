# Changelog

All notable changes to the MIMO-FE website are documented here.

## [0.2.0] - 2026-07-27

### Changed

- Rebuilt the website around the official MIMO-FE console identity.
- Adopted the application's rounded typography and aqua, coral, butter-yellow, and violet palette.
- Moved to a white-first interface with floating buttons, panels, and a console-style mobile dock.
- Replaced the previous logo treatment with the four-color MIMO-FE mark.
- Updated release content to the real `v0.2.0-beta.1` desktop beta.
- Updated every documentation action to the official MIMO-FE wiki.

### Added

- Interactive color selection from the upper-right interface menu.
- Blurred ambient triangles, squares, circles, diamonds, plus signs, and hidden musical notes.
- A light console preview that mirrors the application's HOME mosaic and floating dock.
- A redesigned social sharing card matching the new visual system.

## [0.1.0] - 2026-07-27

### Added

- English landing page for MIMO-FE releases, downloads, documentation, and support.
- Responsive layouts for mobile, tablet, and desktop.
- Fixed desktop navigation with direct access to the MIMO-FE GitHub repository.
- Download calls to action for the application release page.
- Latest-project-update and support sections.
- Social sharing metadata and a custom Open Graph image.
- Production configuration for public deployment on Netlify.
- Security and long-lived static asset cache headers.

### Deployment

- Runtime: Node.js 22.13.0 or later.
- Build command: `npm run build`.
- Publish directory: `.next`.
